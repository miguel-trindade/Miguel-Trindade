# 👨‍💻 Miguel Trindade - Portfólio Pessoal

Portfólio web desenvolvido para apresentar meus projetos, habilidades técnicas, experiências e formas de contato de maneira moderna e responsiva.

## 📖 Sobre o Projeto

Este portfólio foi criado com o objetivo de reunir informações profissionais, projetos desenvolvidos e competências técnicas em um único lugar, facilitando a apresentação do meu perfil para recrutadores, empresas e colaboradores.

O site possui design responsivo e interface intuitiva, proporcionando uma boa experiência em diferentes dispositivos.

## ✨ Funcionalidades

* 🏠 Página inicial personalizada
* 👨‍💻 Apresentação profissional
* 🚀 Exibição de projetos desenvolvidos
* 🛠️ Seção de habilidades técnicas
* 📞 Informações de contato
* 🔗 Links para GitHub e LinkedIn
* 📱 Layout responsivo

## 🚀 Como Executar o Projeto

### Acessar Online

O projeto está disponível através do GitHub Pages.

### Executar Localmente

1. Clone o repositório:

```bash
git clone https://github.com/miguel-trindade/Miguel-Trindade.git
```

2. Acesse a pasta do projeto:

```bash
cd Miguel-Trindade
```

3. Abra o arquivo:

```bash
index.html
```

ou utilize a extensão **Live Server** do VS Code.
