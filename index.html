HTML

É a linguagem de marcação fundamental usada para estruturar e organizar o conteúdo de uma página web, como textos, imagens e links, atuando como o "esqueleto" do site.

CSS

×

CSS

É a linguagem de estilo responsável por definir a apresentação visual (cores, fontes, layout, espaçamento) dos elementos estruturados pelo HTML, sendo a "roupagem" e o "design" do site.

JAVA SCRIPT

×

JAVA SCRIPT

É uma linguagem de programação que adiciona interatividade e dinamismo às páginas web, permitindo manipular elementos, responder a ações do usuário e criar funcionalidades complexas.

MY SQL

×

MY SQL

É um popular sistema de gerenciamento de banco de dados relacional (SGBDR), amplamente utilizado para armazenar, gerenciar e recuperar dados de aplicações web e software em geral.

C#

×

C SHARP

É uma linguagem de programação moderna, orientada a objetos, desenvolvida pela Microsoft, muito usada para construir aplicações desktop, jogos (Unity), serviços web (backend com .NET) e aplicações corporativas.

REDES

×

REDES

É a infraestrutura de interconexão entre dois ou mais dispositivos (computadores, servidores, smartphones) que permite a comunicação, o compartilhamento de recursos e a troca de dados, sendo a base para o funcionamento da Internet e de sistemas internos.

PYTHON

×

PYTHON

O Python é muito utilizado em diversas áreas da tecnologia, como desenvolvimento web, inteligência artificial, análise de dados, automação, criação de jogos e segurança digital. Além disso, é uma das linguagens mais populares do mundo por causa da sua praticidade e grande quantidade de bibliotecas disponíveis.

PHP

×

PHP

O PHP funciona no lado do servidor, ou seja, processa as informações antes de enviá-las para o navegador do usuário. Sua integração com HTML facilita a criação de páginas web interativas, como sistemas de login, cadastros e lojas virtuais.
